# 宝可梦中文化 · 风格指南（Polished Crystal）

本文件规定本项目简体中文化的用词、语气、标点与排版规范，是翻译与校对的唯一风格依据。

## 1. 总原则

1. **忠于原文，语气优先**：先保证剧情信息不丢失，再追求"读起来像官方中文宝可梦"。
2. **官方译名优先**：宝可梦、招式、特性、道具、类型、性格、地点等专有名词一律采用任天堂/The Pokémon Company 官方简体中文译名（见 `GLOSSARY_ZH.md`）。
3. **玩家可见优先**：只翻玩家实际能看到/触发的文本；注释、调试串、`if _DEBUG` 分支的文本不翻。
4. **控制码零丢失**：`<PLAYER>`、`<RIVAL>`、`<NEXT>`、`<LINE>`、`<PARA>`、`<DONE>`、`<NUM>`、`<FAR>`、`<PROMPT>` 等必须在译文中保留且语义等价（详见第 6 节）。

## 2. 语气与人称

| 场景 | 语气 | 示例 |
|---|---|---|
| 旁白 / 系统提示 | 中性、简洁 | 「宝可梦已恢复到最佳状态！」 |
| 路人 NPC | 口语、活泼 | 「哇！你的宝可梦好厉害呀！」 |
| 博士 / 教授 | 稳重、专业 | 「这就是宝可梦与人类共存的证据。」 |
| 对手 | 自信、带点挑衅 | 「哼，这种程度也想赢我？」 |
| 反派（火箭队等） | 嚣张、戏剧化 | 「把那只宝可梦交出来！」 |
| 战斗提示 | 干脆、标准 | 「效果绝佳！」「很遗憾，没有命中。」 |

- 游戏内旁白默认**不出现第一人称叙述者**，与官方作品一致。
- 玩家角色发言尽量保持性格中性，避免强加人设。

## 3. 标点规范

- 使用**全角标点**：，。！？：；、（）、——……
- 省略号统一用 **……**（两个全角省略号字符），不写 `...` 或 `。。。`。
- 引号使用 **「」**（官方中文宝可梦在对话框内的习惯），书名/招式名不额外加引号。
- 破折号用 **——**。
- 慎用感叹号，连续感叹号最多一个：`！！` 仅在极端情绪处使用。
- 数字沿用**半角阿拉伯数字**（与英文版一致，`<NUM>` 控制码输出保持半角）。
- 英文专有名词（如"Poké"相关保留词）如需出现，保持原始大小写。

## 4. 术语一致

- 统一用词（左为统一译法）：宝可梦 / 训练家 / 道馆 / 道馆馆主 / 四天王 / 冠军 / 精灵球 / 图鉴 / 招式 / 特性 / 携带物品 / 果实 / 徽章 / 经验值 / 等级 / 体力（HP 在界面中保留 "HP"）。
- **招式**：使用官方招式名（如"十万伏特"、"飞叶快刀"）。
- **道具**：使用官方道具名（如"精灵球"、"伤药"、"离洞绳"）。
- **类型**：使用官方类型名（一般、火、水、草、电、冰、格斗、毒、地面、飞行、超能力、虫、岩石、幽灵、龙、恶、钢、妖精；第二世代无妖精）。
- **特性**：第二世代无特性，若改版引入则以官方译名为准。
- **性格**：官方性格名（勤奋、怕寂寞、勇敢……）。

## 5. 排版与行长（技术约束）

本项目正文使用 **12×12 点阵汉字**，占 **2×2 个 8×8 tile 单元**。

- 对话框内每行最多 **9 个汉字**（或等价宽度：1 个汉字 = 2 个半角字符宽度）。
- 半角字符（英文/数字）= 1 个 tile 宽；汉字 = 2 个 tile 宽。
- 文本框内宽 `TEXTBOX_INNERW = SCREEN_WIDTH - BORDER_WIDTH = 18` tile，即 **18 个半角字符** 或 **9 个汉字/行**。
- **对话不会自动换行**，必须由译者在适当位置插入 `<NEXT>`/`<LINE>`/`<PARA>`/`<CONT>`，并保证每行宽度 ≤ 18 tile。
- 译文长度不得使行长溢出，否则会出现文字被截断或串行。
- 名称类文本（宝可梦/招式/道具名）在界面中按可变宽度显示，避免超出既有栏宽。

## 6. 控制码约定（必须遵守）

| 控制码 | 含义 | 翻译注意 |
|---|---|---|
| `<PLAYER>` / `<RIVAL>` | 玩家/对手名字 | 原样保留 |
| `<TARGET>` / `<USER>` / `<ENEMY>` | 战斗中的宝可梦名 | 原样保留，顺序不变 |
| `<NEXT>` | 换行（行距不变） | 自行安排换行位置 |
| `<LINE>` | 换到文本框下一段起始行 | 原样保留 |
| `<PARA>` / `<CONT>` | 分页/等待玩家按键 | 与原意一致 |
| `<DONE>` / `@` | 字符串结束 | 必须结尾存在 |
| `<NUM>` | 插入十进制数字 | 后随 3 字节参数不可改动 |
| `<FAR>` | 跨 bank 字符串引用 | 后随指针参数不可改动 |
| `<ASM>` | 调用汇编例程 | 后随地址参数不可改动 |
| `<PAUSE>` / `<SOUND>` / `<DAY>` / `<PLURAL>` | 各类特殊命令 | 参数不可改动 |

> 转码工具会校验"原文与译文的控制码序列完全一致"，不一致将报错。

## 7. 命名（玩家/昵称）

- 玩家名、对手名、宝可梦昵称**仍使用英文/数字输入**（保留原 QWERTY 界面），不做拼音输入。
- 中文提示语中引用玩家名时使用 `<PLAYER>`/`<RIVAL>`，不要硬编码名字。

## 8. 校对手册

1. 术语是否与 `GLOSSARY_ZH.md` 一致；
2. 控制码数量与顺序是否与原文一致；
3. 每行宽度是否 ≤ 18 tile；
4. 是否有"机翻腔"（如"我将会去做"→"我会去做"）；
5. 标点是否全角、省略号是否为 `……`；
6. 是否误翻了调试/未使用文本。
